# Dicionário de Dados

## Objetivo

Definir os elementos, atributos e significados dos dados da plataforma ELO.

## Escopo

- entidades de dados
- atributos
- tipos de dados
- chaves
- regras de domínio associadas aos dados

## Regras

- o dicionário deve ser rastreável ao modelo lógico
- a nomenclatura deve ser consistente em todo o repositório
- alterações estruturais devem ser refletidas na documentação
