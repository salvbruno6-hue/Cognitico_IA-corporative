# Modelo Lógico

## Objetivo

Descrever a estrutura lógica do modelo de dados do ELO.

## Escopo

- tabelas lógicas
- chaves primárias e estrangeiras
- integridade referencial
- relações entre dados

## Regras

- o modelo lógico deve ser rastreável ao modelo conceitual
- a implementação física deve respeitar a separação de responsabilidades
- o desenho deve suportar evolução incremental
