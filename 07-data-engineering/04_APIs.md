# APIs

## Objetivo

Definir a camada de exposição e consumo de serviços da plataforma ELO.

## Escopo

- contratos HTTP
- rotas de integração
- padrões de request e response
- versionamento de API

## Regras

- APIs devem ser orientadas a contratos estáveis
- a camada de API não deve conter regras centrais de negócio
- qualquer integração externa deve respeitar os contratos definidos neste repositório
