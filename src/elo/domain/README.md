# ELO Domain

Camada de domínio do ELO.

## Responsabilidade

Conter as regras centrais, entidades, objetos de valor, agregados, serviços de domínio e eventos do negócio.

## Subcamadas

- entities
- value_objects
- aggregates
- services
- events

## Regra

Esta camada não deve depender de infraestrutura, APIs externas ou detalhes de persistência.
