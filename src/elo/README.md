# ELO Core

## Missão

O diretório `src/elo` concentra a implementação do núcleo do ELO.

## Camadas

- domain
- application
- infrastructure
- adapters
- contracts
- tests

## Princípios

- Separação entre domínio e infraestrutura.
- Código orientado a casos de uso.
- Integrações externas desacopladas.
- IA será adicionada posteriormente por meio de adaptadores.
