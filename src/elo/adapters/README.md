# ELO Adapters

Camada de adaptadores do ELO.

## Responsabilidade

Conter interfaces para comunicação com o mundo externo, incluindo API, banco de dados, documentos e integrações.

## Subcamadas

- api
- database
- documents
- integrations

## Regra

Esta camada adapta o domínio e a aplicação para os contratos e formatos exigidos por sistemas externos.
