# ELO External Access Control Matrix

| Session | Repository access | Business consultation | Domain evidence | Write | Core promotion | Other repositories |
|---|---|---|---|---|---|---|
| READ_ONLY_CONSULTATION | read-only | yes | no | no | no | no |
| AUTHORIZED_SPECIALIST | minimum required scope | yes | yes | only if separately authorized | no direct promotion | no |
| GOVERNED_EXECUTION | explicit authorized scope | yes | yes | governed | through Evolution Gate | only if separately authorized |
| ADMIN/GOVERNANCE | separately controlled | yes | yes | governed | governed | separately controlled |

## Non-negotiable controls

1. ELO policy does not replace GitHub permissions.
2. Read-only integrations use read-only credentials.
3. Specialists receive least-privilege access limited to authorized scope.
4. Broader GitHub privileges are not treated as ELO authorization.
5. Cross-company data remains isolated unless separately authorized.
6. Natural-language commands do not grant repository write permission.
7. Core changes require governed proposal, validation, generalization and Evolution Gate.
