# ELO Core — Systemic Intelligence Primitives

## Purpose

Provide small provider-neutral value objects for systemic reasoning. These primitives are faculty, not an execution engine.

## Canonical ownership

- Cognitive: defines identity, invariants and authority.
- Core: owns these general reusable primitives and mechanisms.
- Forge: supplies specialist evidence, contextual parameters and experiences.
- Application/Infrastructure: provide interfaces and replaceable means.

## Primitives

- `SystemicModel`: entities and evidence-backed relationships.
- `CausalAssessment`: bounded cause/effect assessment with confidence and evidence.
- `DecisionRecord`: decision, rationale, impact, evidence and authority boundary.
- `OutcomeFeedback`: expected versus observed outcome.
- `TemporalValidity`: validity window and last confirmation.
- `UncertaintyAssessment`: confidence, uncertainty and limitations.
- `Scenario`: bounded simulation value object; it does not execute actions.

## Rules

1. No primitive persists its own memory.
2. No primitive executes an enterprise action.
3. Evidence and confidence remain explicit.
4. Existing Context, Evidence, Decision, Memory and Provenance mechanisms remain the canonical integration points.
5. Scenario is not a second scenario engine and does not replace diagnostic scenario ownership.
6. Promotion of any learning derived from these primitives remains subject to the existing Evolution Gate.
7. Provider neutrality is mandatory.

## Maturity meaning

These primitives improve ELO's ability to connect relationships, assess causality, record decisions, compare outcomes and reason under time/uncertainty. They do not by themselves constitute autonomous budgeting or autonomous execution.
