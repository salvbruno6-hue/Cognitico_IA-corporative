# Exemplos de uso do ELO

O ELO entende português natural. Você não precisa saber JSON,
issue ou label. Basta falar.

## Como acionar

Peça ao ChatGPT:

> "Cria uma issue no repositório com esse comando:
> ELO, confere essa análise da SO 155.26: [sua análise]"

O ChatGPT cria a issue automaticamente.

## Exemplos

### Conferir uma análise

"ELO, confere essa análise da SO 155.26: o orçamento contempla
24 módulos, manutenção de 6 meses, ART/RRT sobre projetos."

O ELO responde com:
- o que está alinhado
- o que pode melhorar
- o que precisa corrigir
- o que conflita com política

### Saber o que o ELO sabe

"ELO, o que você sabe sobre a SO 155.26"

### Guardar aprendizado

"ELO, guarda isso da SO 155.26: usar premissa de 30% para peças
de manutenção quando o quantitativo não estiver documentado."

### Consultar decisão

"ELO, como está a decisão DEC_2026_0001"

### Ver pendências

"ELO, o que está aberto"

### Buscar precedente

"ELO, já vimos algo parecido com a SO 155.26"
