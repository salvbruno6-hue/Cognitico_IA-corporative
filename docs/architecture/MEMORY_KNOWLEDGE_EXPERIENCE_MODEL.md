# ELO — Memory, Knowledge and Experience Model

## Principle

Memory preserves history. Knowledge represents validated reusable cognition. Experience preserves what happened in context.

## Forge experience record

Each experience preserves:
- original exercise/context;
- source excerpt(s);
- extracted information;
- hypotheses/premises;
- analysis;
- decisions;
- evidence;
- actions;
- results;
- follow-ups;
- feedback;
- derived contextual parameters;
- later applications.

The original record remains preserved until and after feedback. New feedback changes state/version, not historical content.

## Source provenance

`origin` identifies only where the information was extracted from: the source document, record, event, or exact relevant excerpt. Interpretation and reasoning belong to analysis, not origin.

## Follow-up lifecycle

```text
experience
 → premise
 → test
 → awaiting feedback
 → feedback
 → comparison
 → contextual/general parameter candidate
 → application
 → reassessment
```

An open follow-up must retain its relationship to the original exercise and remain addressable in later cycles.

## Core memory

Core memory contains validated generalized knowledge, general parameters, canonical evolution history and governance state. It does not replace Forge experience.

## Complex experience retention

Experiences with broad end-to-end relationships, multiple sectors/specialists, consequential decisions or high-impact results remain fully preserved in Forge. Generalized learning may be promoted to Core without transferring the entire operational case.

## Immutable history

A later correction, feedback event, or parameter revision must not erase the earlier state. The system records supersession, invalidation or revision explicitly.
