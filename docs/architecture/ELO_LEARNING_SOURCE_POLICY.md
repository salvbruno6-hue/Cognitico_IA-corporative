# ELO Learning Source Policy

Every externally or operationally produced learning item must preserve its
source, tenant, evidence and outcome context.

## Learning classes

- `CORPORATE`: company-specific practice or rule candidate.
- `TECHNICAL`: implementation or architectural observation.
- `EXPERIENCE`: observed result from a real operation.
- `HYPOTHESIS`: unconfirmed explanation or pattern.
- `RULE`: governed knowledge after validation and promotion.

## Automatic collection

ELO may collect useful observations automatically from governed workflows,
AI providers, specialists, plugins, calculations and user interactions when
those interactions are within the authorized tenant context.

Automatic collection is not automatic truth. Collection enters the Learning
Laboratory first.

## Promotion

Promotion requires evidence and the existing validation/Evolution Gate path.
No AI response, plugin output or user statement alone can silently rewrite
canonical Core knowledge or the Soul.
