# ELO Aprender — Síntese de padrão de decisão

## Objetivo

A etapa de síntese transforma uma experiência concreta em um padrão de decisão reutilizável. A decisão original da SO permanece evidência de origem; ela não é copiada para o conhecimento canônico como regra específica.

Fluxo:

DECISÃO DA SO → EXPERIÊNCIA → SÍNTESE → PADRÃO DE DECISÃO CANDIDATO → GOVERNANÇA / VALIDAÇÃO → PADRÃO DE RACIOCÍNIO VALIDADO

## Contrato da síntese

A síntese preserva:
- gatilho — condição que levou à decisão;
- pré-requisitos — evidências/dependências necessárias;
- sequência — caminho de raciocínio;
- regras de decisão — relação condicional generalizada;
- heurísticas — orientações auxiliares;
- limitações — quando não aplicar;
- evidências — resultado/verificação e origem;
- proveniência — experiência que originou o padrão;
- status — inicialmente CANDIDATO.

## Regra central

O padrão deve responder:

"Quando uma nova SO apresentar condição semelhante, qual caminho de decisão deve ser consultado?"

Ele não deve responder:

"Qual foi a solução adotada na SO de origem?"

## Caso de arbitragem ausente

Quando a experiência registra ausência ou insuficiência de arbitragem externa, a síntese produz orientação condicional:
1. identificar a dúvida atual;
2. consultar orientação interna previamente aprendida;
3. verificar equivalência e aplicabilidade;
4. formular premissa limitada à evidência;
5. submeter a decisão ao analista;
6. registrar o resultado para futura validação.

O histórico permanece consultivo. Não há aplicação automática e não há transformação de uma única SO em regra universal.

## Limite de promoção

A função de síntese não grava no Supabase e não promove conhecimento. Ela produz uma estrutura candidata compatível com elo_aprendizado_padroes_raciocinio.

A promoção continua pertencendo ao ciclo cognitivo e ao gate canônico.
