# ELO Symbiotic Intelligence Principle

ELO maximizes governed use of available cognitive capabilities instead of
replicating every capability internally.

## Responsibilities

- **ELO/Core:** mission understanding, context composition, capability
  selection, governance, evidence, critique, decision support and learning.
- **Specialists:** domain judgment and human validation where required.
- **External AI/providers:** specialized cognitive execution.
- **Plugins/tools:** specialized operational capabilities.
- **Learning Laboratory:** isolated evidence-bearing experience and learning
  candidates.
- **Canonical knowledge:** only receives governed, validated promotions.

## Loop

`MISSION → DECOMPOSE → SPECIALISTS → CAPABILITIES → PROVIDER/PLUGIN → RESULT → CRITIQUE → OUTCOME → EXPERIENCE → LEARNING CANDIDATE → VALIDATION → PROMOTION`

The Intelligence Router should learn from evidence and outcomes which provider,
model, specialist, tool, context and instruction perform better for each class
of mission. It must not assume a permanent provider-to-domain mapping.

## User experience

Users may interact with ELO as the governed workspace and may be granted
access to external AI capabilities inside that workspace. External providers
remain replaceable capabilities; ELO remains the orchestration and governance
boundary.
