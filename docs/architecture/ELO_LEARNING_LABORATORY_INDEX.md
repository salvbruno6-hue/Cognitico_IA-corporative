# ELO Learning Laboratory

Implemented boundary: `src/elo/core/learning_laboratory.py`.

The laboratory separates raw operational experience and AI/provider outputs
from canonical knowledge. Evidence is required for candidate creation, and
validation is required before promotion.

See `ELO_GOVERNED_LEARNING_LABORATORY.md` and
`ELO_LEARNING_SOURCE_POLICY.md` for the governing model.
