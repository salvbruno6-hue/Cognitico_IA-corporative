# ELO Budget Symbiotic POC — Execution Matrix

| Stage | Existing authority | Required output | Gate |
|---|---|---|---|
| Identity | tenant/governance contracts | tenant + principal | isolation |
| Mission | Cognitive | objective + scope | complete request |
| Capability | existing registry | budgeting/reasoning/tool needs | capability exists |
| Route | `ExecutionRouter` | model/tool decision | auditable rationale |
| Provider | governed adapter | AI execution | authorized adapter |
| Context | existing context/memory | corporate context | tenant-scoped |
| Evidence | existing evidence/provenance | source-backed inputs | no unsupported facts |
| Budget | `GovernedBudgetingService` | versioned budget | GAP/conflict rules |
| Critique | reasoning/critique | defects/uncertainties | review |
| Decision | budgeting decision contract | recommendation + authority | approval separated |
| Outcome | outcome feedback | expected vs observed | evidence |
| Learning | Learning Laboratory | experience/candidate | validation |
| Evolution | Evolution Gate | governed promotion | explicit approval |

## Failure policy

A failed stage blocks advancement rather than being silently skipped. The POC
must preserve the failed stage, reason and evidence needed for correction.

## Success criterion

The POC is successful only when the result is both operationally useful and
auditable from mission through outcome and learning. Producing a budget alone is
insufficient evidence of convergence.
