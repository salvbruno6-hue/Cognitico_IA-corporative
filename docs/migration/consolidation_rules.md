# ELO Consolidation Rules

## Regras oficiais

1. Nenhuma informação estratégica será perdida.
2. Documentos duplicados serão comparados antes da consolidação.
3. A versão mais madura será considerada referência.
4. Histórico e origem serão preservados.
5. Alterações estruturais deverão possuir ADR.

## Critérios de Baseline

- Coerência arquitetural.
- Rastreabilidade.
- Capacidade evolutiva.
- Alinhamento com a filosofia cognitiva ELO.
