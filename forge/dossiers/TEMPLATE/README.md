# Template — Dossiê SO

Este diretório contém o template de um dossiê SO. Não é um
dossiê real.

## Como usar

1. Copiar este diretório
2. Renomear para SO_<NNN>_<AA> (ex: SO_155_26)
3. Preencher identity.json com dados da SO
4. Criar context.md com o resumo contextual
5. Criar provenance.json com as referências
6. Criar status.json com o estado de maturação

## Arquivos esperados em um dossiê real

- identity.json       — identidade canônica + escopo
- context.md          — resumo contextual
- provenance.json     — referências às fontes
- status.json         — estado de maturação

## Importante

O dossiê NÃO copia o conteúdo das fontes. Ele apenas
referencia. Conforme ELO_CONTEXT_ASSEMBLY_CONTRACT.
