# ELO Read-Only Consultation Acceptance

Default external session:

`ELO SESSION = READY | MODE = READ_ONLY_CONSULTATION | WRITE = DISABLED`

The connected AI may search, ask, inspect, compare, analyze and recommend from repository evidence.

It may not modify files, Issues, PRs, Core, Forge, canonical memory, governance, branches, tags or external production systems in consultation mode.

Requested changes must remain proposals until explicit authorization transitions the session to governed execution.

Missing or conflicting evidence must be reported as GAP/uncertainty rather than invented.
