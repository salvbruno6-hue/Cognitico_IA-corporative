# ELO — Cognitive Capability Matrix — 2026-08

## Purpose

Define the native ELO capabilities derived from external research without importing external projects as architectural authorities.

## Admission rule

External source → technical extraction → ELO adaptation → executable test → benchmark → governance → canonical promotion.

No external implementation may directly modify Soul, Canon, Core sovereignty, or tenant boundaries.

## Capability matrix

| Capability | Research basis | Native ELO boundary | Initial maturity | Promotion condition |
|---|---|---|---|---|
| Cognitive program optimization | DSPy | `cognitive.optimization` | experimental | reproducible gain without unacceptable regression |
| Typed memory | Agent Memory Techniques | `cognitive.memory` | experimental | isolation + retrieval benchmarks |
| Cognitive routing | Semantic Router | `cognitive.routing` | experimental | route quality + latency benchmark |
| Deliberative search | Tree of Thoughts | `cognitive.reasoning` | experimental | benchmarked gain over direct reasoning |
| Verification | reasoning/evaluation research | `cognitive.verification` | experimental | false-acceptance regression suite |
| Context normalization | agent/context architectures | `cognitive.context` | experimental | provenance and scope tests |
| Inference abstraction | vLLM / llama.cpp | `cognitive.inference` | interface | provider interchangeability |
| Evidence-based evolution | DSPy/evaluation/agent optimization | Forge governance | experimental | reproducible experiment + approval |

## Runtime principle

The ELO should select the least expensive cognitive path that satisfies the required quality, confidence, risk, and evidence thresholds.

## Tenant isolation

Canonical knowledge and tenant knowledge are distinct classes. Tenant data may contribute to a local decision but must not be promoted to Canon without an explicit governed transformation that removes enterprise-specific information and passes the canonical admission process.

## Evolution loop

Observe → detect limitation → formulate hypothesis → experiment → measure → compare → verify → propose → govern → promote/reject.
