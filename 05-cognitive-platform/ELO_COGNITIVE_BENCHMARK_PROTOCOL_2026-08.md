# ELO Cognitive Benchmark Protocol — 2026-08

## Purpose

Measure whether a cognitive capability actually improves ELO behavior rather than merely changing implementation.

## Required dimensions

- correctness
- groundedness
- confidence
- latency
- cost
- regression rate
- tenant-boundary compliance
- Canon immutability

## Evolution loop

```text
freeze baseline
    ↓
representative cases
    ↓
measure
    ↓
candidate
    ↓
paired comparison
    ↓
regression suite
    ↓
provenance review
    ↓
promotion proposal
    ↓
governance
```

No single metric is sufficient to promote a capability. A quality gain cannot compensate for a governance, isolation, or regression failure.
