# ELO Experience Learning Contract

## Purpose

Define how execution experience becomes governed learning evidence without silently modifying Canon or tenant methodology.

## Lifecycle

```text
EXECUTION
  -> TRACE
  -> VERIFICATION
  -> EVALUATION
  -> LEARNING CANDIDATE
  -> FORGE EXPERIMENT
  -> REGRESSION
  -> GOVERNANCE
  -> PROMOTION
```

## Required provenance

Each candidate retains tenant scope, capability, context, selected model/tool, result, verification state, quality, reliability and efficiency.

## Promotion boundary

A verified experience is only a `candidate`. Promotion requires Forge evaluation and governance. Tenant-specific evidence cannot become Canon merely through repetition.

## Failure rule

Unverified, contradictory or insufficiently evidenced experiences must not become learning candidates.
