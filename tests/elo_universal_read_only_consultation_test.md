# ELO Universal Read-Only Consultation Acceptance

- [ ] Bootstrap identifies ELO without prior conversation.
- [ ] Default session is `READ_ONLY_CONSULTATION`.
- [ ] Manifest declares `write=false` and `external_actions=false`.
- [ ] AI can search and answer from repository evidence.
- [ ] AI can inspect Issues, PRs and workflow evidence.
- [ ] AI distinguishes documented, contracted, implemented, tested, verified and Evolution-Gated capabilities.
- [ ] Consultation mode cannot modify files, Issues, PRs, Core, Forge or canonical memory.
- [ ] Requested changes become proposals and require explicit authorization.
- [ ] Missing/conflicting evidence becomes GAP/uncertainty rather than invented data.
- [ ] Consultation-only integrations use read-only Git credentials where possible.
