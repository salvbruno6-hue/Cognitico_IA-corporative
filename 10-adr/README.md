# ADR — Architecture Decision Records

ADRs registram decisões arquiteturais relevantes e devem ser usadas quando uma alteração muda boundaries, contratos, autoridade, segurança, tenancy, provenance, autonomia ou outros aspectos estruturais do ELO.

A ADR não substitui a implementação nem os testes.

## Relação com maturidade

```text
ADR
 ↓
Contract
 ↓
Implementation
 ↓
Test
 ↓
Evidence
```

Uma ADR `proposed` não autoriza automaticamente implementação.
