## Aprendizados técnicos relevantes

### Rede de dados

A infraestrutura de dados deve ser analisada a partir dos layouts, quantidade de bases de trabalho e pontos necessários. A ausência de atribuição expressa não autoriza assumir switch, roteador, access point Wi-Fi, modem/ONU ou link de internet. O raciocínio deve distinguir infraestrutura passiva de ativos de rede.

### Climatização

A verba unitária usada na composição de instalação foi estruturada para cobrir kit de instalação de 5 m, acessórios, dreno, suporte para condensadora e mão de obra. A quantidade deve seguir o layout/TR de cada CETA.

### Esgoto sanitário

A composição deve distinguir infraestrutura externa de interligação do módulo ao sistema existente e infraestrutura interna do módulo. Em Macapá, a configuração de dois módulos e maior extensão hidrossanitária justificou valor superior registrado de R$ 4.337,47, contra R$ 2.022,64 nas demais CETAs onde essa premissa foi aplicada.

### Bases

Foi adotado conjunto de 6 blocos pré-fabricados de concreto armado de 30 × 30 × 30 cm por contêiner, com valor de referência de R$ 630,00 por conjunto.

### Macapá

Macapá possui configuração com dois módulos e recebeu tratamento específico para isotelha PIR 30 mm + estrutura de telhado em metalon. O quantitativo de piso foi validado considerando a área efetiva do conjunto dos dois reefers. O fechamento inferior foi posteriormente ajustado para R$ 3.800,00 para atender os dois módulos.

### Quadro externo

A lógica definida foi separar o quadro interno do quadro externo destinado à alimentação geral e interligação ao quadro interno. O quadro externo foi concebido como solução de facilitação da ligação do contêiner, com proteção geral e dispositivos pertinentes, devendo permanecer distinguido da instalação interna.

## Regra de aprendizado

Não registrar somente valores. Para cada item relevante, reconstruir a cadeia:

`fonte → requisito → interpretação → solução → quantitativo → composição → valor → justificativa → premissa → risco → decisão → resultado`.
