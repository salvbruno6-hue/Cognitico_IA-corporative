## Aprendizado operacional para orçamento
1. Usar as características efetivamente indicadas no desenho como base de comparação para o padrão modular.
2. Separar claramente o que é configuração padrão do módulo do que for solicitado como adicional/excedente.
3. Não assumir que um item citado em outra solicitação pertence ao layout de referência sem evidência documental.
4. Para alterações estruturais em módulo (novos vãos, equipamentos, reforços ou sistemas de movimentação), tratar como requisito específico e verificar necessidade de validação estrutural.
5. Para elétrica, registrar a alimentação e os pontos efetivamente representados no layout antes de classificar itens como padrão ou excedente.
6. Para hidráulica e esgoto, considerar apenas os pontos/configurações sustentados pelo desenho ou pela solicitação correspondente.
