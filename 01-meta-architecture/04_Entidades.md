# Entidades

## Objetivo

Definir as entidades fundamentais do domínio do ELO.

## Entidades previstas

- conhecimento
- documento
- ativo
- usuário
- domínio
- capacidade

## Regras

- cada entidade deve possuir identidade própria
- a entidade deve refletir um conceito estável do domínio
- a definição deve ser compatível com o modelo conceitual
