# ELO-ORG — Organizational Intelligence Member

## Purpose

ELO-ORG represents the organization's structural model for use by the ELO orchestrator. It describes how domains, processes, modules, entities, specialists, standards, dependencies, indicators, and management views relate.

## Scope

### In scope
- organizational domains and subdomains;
- processes and subprocesses;
- modules and capabilities;
- business entities and relationships;
- specialist roles and responsibilities;
- dependencies and interfaces;
- standards, taxonomies and controlled vocabulary;
- indicators and management-view definitions;
- structural provenance and versioning.

### Out of scope
- cognitive decision authority;
- global memory authority;
- provider/model orchestration;
- execution of operational transactions;
- replacing domain specialists;
- creating a second Cognitive Core.

## Canonical domains for the current model

- Comercial
- Licitações
- Orçamento
- Projetos / Engenharia
- Compras / Suprimentos
- Produção
- PCP
- Logística / Expedição
- Resultado / Pós-execução

Comercial and Licitações are independent domains even when grouped under the same business macro-process.

## Architectural role

ELO-ORG answers structural questions such as:

- who owns a process;
- which domain provides or consumes an output;
- what dependencies exist;
- which specialist or source has domain authority;
- which indicators represent a process;
- which version of the organizational model is active.

The ELO Core uses these answers as governed context. It must independently evaluate evidence, conflicts, uncertainty and decision implications.
