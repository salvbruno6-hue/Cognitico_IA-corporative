# SQLite

## Objetivo

Estabelecer a estratégia física de persistência inicial da plataforma ELO usando SQLite.

## Escopo

- banco local
- estrutura de tabelas
- integridade relacional
- evolução futura para outros mecanismos

## Regras

- SQLite é a base inicial de referência para prototipação e baseline
- a documentação deve acompanhar o esquema físico
- qualquer migração futura deve preservar rastreabilidade
