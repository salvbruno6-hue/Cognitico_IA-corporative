# ELO — APRENDIZADO: CONCRETAGEM / RADIER — SO 082.26

**Origem:** SO 082.26 — Comando da Aeronáutica / Licitações — Boa Vista/RR
**Contexto:** análise de excedentes e composição orçamentária.

## 1. Dados padrão para levantamento de concretagem

Utilizar como formulário-base:
- Dados do cliente: razão social, CPF/CNPJ, responsável, telefone e e-mail;
- Endereço da obra: endereço, CEP e referência;
- Tipo de serviço: laje, piso, fundação, pilar/viga ou outro;
- Volume solicitado em m³;
- FCK;
- Slump desejado: 100 ± 20 mm;
- Necessidade de bombeamento;
- Tipo de bomba: estacionária ou bomba lança.

## 2. Aplicação em radier para módulos/container

Para radier destinado a módulos containerizados, o FCK não deve ser definido somente pelo preço do concreto. A composição deve considerar espessura, armadura, cargas dos módulos, solo, condições de apoio e projeto estrutural.

Como referência de orçamento preliminar usada nesta análise, 30 MPa foi adotado como premissa comercial/técnica para radier de módulo, sujeito à validação do responsável técnico e do projeto.

Não registrar 30 MPa como mínimo normativo universal. O valor normativo aplicável depende do elemento, classe de agressividade, sistema estrutural e norma/projeto vigente.

## 3. Regra de composição do excedente

Para fundação/radier, estruturar o custo por:
- concreto usinado;
- armadura;
- formas, quando aplicável;
- preparo/compactação da base;
- lona/barreira;
- mão de obra;
- bomba, se necessária;
- equipamentos;
- transporte/mobilização;
- perdas justificadas.

Fluxo:
REQUISITO → BASE → EXCEDENTE → QUANTITATIVO → INSUMOS → MÃO DE OBRA → EQUIPAMENTOS → LOGÍSTICA → VALOR.

## 4. Excedentes comerciais observados na SO 082.26

Itens a verificar/cotar separadamente:
- fundação radier;
- concreto usinado;
- porta de correr 80 cm;
- porcelanato 60x60;
- aparelhos de ar-condicionado;
- caminhão Munck;
- painel térmico/isotérmico de 32 mm, quando aplicável.

## 5. Regra de preço

Nenhum valor deve ser tratado como padrão reutilizável apenas por estimativa. Para virar referência da biblioteca, registrar fonte, data, local, unidade, escopo e condições de execução, preservando o contexto de Boa Vista/RR quando aplicável.

**Status do aprendizado:** referência operacional para futuras SOs; preços específicos permanecem estimativas até validação por fornecedor/mercado.
