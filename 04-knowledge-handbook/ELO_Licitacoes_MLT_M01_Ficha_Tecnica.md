# MLT.M01 — Módulo Amplo 20 pés — FICHA NORMALIZADA

## 1. Identificação

| Campo | Valor oficial do modelo |
|---|---|
| Modelo | MLT.M01 – Módulo Amplo 20 pés |
| Classe | Módulo 20 pés – Uso Geral / Escritório |
| Aplicação | Escritório, alojamento, apoio operacional ou uso geral |
| Comprimento externo | 6000 mm |
| Largura externa | 2440 mm |
| Altura externa específica do MLT.M01 | **2985 mm** |
| Área externa/nominal | **14,64 m²** |
| Área útil interna de referência para 20 pés | **13,62 m²** |

### Regra de área
O valor de **14,64 m²** corresponde à área nominal externa obtida pelas dimensões 6000 × 2440 mm. Portanto, **não deve ser apresentado como área útil interna**.

Para o MLT.M01, a área útil deve ser tratada como **13,62 m²**, conforme regra corporativa de área útil dos módulos de 20 pés, até existir uma ficha dimensional interna específica que substitua esse valor.

## 2. Componentes construtivos

| Campo | Especificação |
|---|---|
| Estrutura metálica | Estrutura modular galvanizada composta por perfis UDC enrijecidos, colunas estruturais conformadas, travamentos metálicos e conectores de içamento integrados. |
| Cobertura externa | Telhado formato bacia com telhas de fibra translúcida de aproximadamente 4 mm, fixadas por parafusos galvanizados e arruelas de vedação. |

| Piso estrutural | Painel Wall **30 mm** apoiado sobre o chassi estrutural. |
| Revestimento de piso | Piso vinílico LVT **2 mm**, quando previsto nesta configuração. |
| Isolamento térmico | Núcleo PIR com condutividade térmica aproximada informada de **0,022 W/m·K**. |
| Vedação | Encaixe macho-fêmea e selagem dos encontros estruturais/painéis. |

## 3. Proteção e pintura

- A estrutura principal é galvanizada.
- **Não aplicar Shop Primer como revestimento geral sobre superfícies galvanizadas íntegras.**
- Nas regiões de solda, cortes, cantos, arestas ou pontos em que a galvanização tenha sido removida/danificada, executar o tratamento de recuperação especificado.
- Acabamento estrutural: **PU W-Thane PDA 514**, quando previsto no sistema de pintura do modelo.

A alimentação **220 V monofásica** é específica desta ficha e prevalece sobre a descrição elétrica geral da família MLT quando a pergunta for sobre o MLT.M01.

A descrição geral **127/220 V – 2F + N + T** não deve ser atribuída automaticamente ao MLT.M01.

## 6. DR e DPS

- **MLT.M01: DR e DPS não são configuração padrão**, conforme esta ficha.
- DR/DPS são associados ao cadastro dos **módulos sanitários e áreas molhadas**, conforme configuração/projeto aplicável.
- Se houver exigência de projeto ou normativa para uma configuração específica, a análise deve ser feita pelo responsável técnico.
