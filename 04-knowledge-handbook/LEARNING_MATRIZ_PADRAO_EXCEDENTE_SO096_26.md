# ELO APRENDER — Matriz Padrão × Excedente — SO 096.26 FIRJAN/SENAI

**Tipo:** Aprendizado técnico de orçamento
**Referência:** SO 096.26 — FIRJAN/SENAI — Maracanã/RJ

## 1. Regra aprendida

Quando a SO exigir adequação de um módulo já existente no catálogo Multiteiner, o orçamento deve partir da composição padrão do modelo e calcular somente o **delta técnico** necessário para atendimento ao cliente.

Fluxo:

**PADRÃO DO MODELO → REQUISITO DA SO → COMPARAÇÃO → DIFERENÇA → EXCEDENTE → ORÇAMENTO**

Não duplicar itens que já fazem parte da composição padrão.

## 2. Aplicação prática — elétrica

Na SO 096.26, o módulo amplo já possui parte da instalação elétrica. O cliente solicitou quadro com alimentação trifásica de 50A e três circuitos de tomadas de 16A.

Metodologia aplicada:

- o circuito/disjuntor já existente no módulo padrão não deve ser cobrado novamente;
- o disjuntor bipolar 25A já contemplado no padrão não deve ser duplicado;
- se o cliente exige três circuitos de 16A e o padrão já possui um, cobrar somente os **dois circuitos adicionais**;
- acrescentar apenas os componentes necessários para a transformação da alimentação/quadros ao padrão solicitado, conforme validação técnica do cliente.

## 3. Regra para futuras SOs

Para cada sistema, registrar:

| Requisito | Padrão | Diferença | Excedente |
|---|---|---|---|
| Elétrica | composição M01/Módulo Amplo | o que o cliente acrescenta/altera | somente o delta |
| Porta | porta padrão | porta especial | diferença de fabricação |
| Painel | especificação padrão vigente | espessura/material solicitado | diferença de fornecimento |
| Climatização | equipamento padrão | capacidade/configuração solicitada | diferença efetiva |

## 4. Princípio de controle

**Não orçar novamente aquilo que já está contido no modelo-base.**

A análise deve identificar item por item o que é:

- PADRÃO;
- ADAPTAÇÃO;
- EXCEDENTE;
- PENDÊNCIA DE ESCLARECIMENTO.

## 5. Exemplo consolidado da SO 096.26

O orçamento de elétrica foi estruturado como adequação do padrão do módulo, não como uma nova instalação elétrica completa.

Isso resultou em um orçamento mais competitivo e evita sobreposição de custos.
