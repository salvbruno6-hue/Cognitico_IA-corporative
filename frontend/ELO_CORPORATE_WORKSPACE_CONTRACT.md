# ELO Corporate Workspace Contract

## Purpose

Define the product surface for corporate intelligence without creating parallel business logic or cognitive authority.

## Canonical areas

- Corporate Overview
- Intelligence
- Decisions
- Budgets
- Projects/Works
- Engineering
- PCP
- Supply
- Commercial
- Contracts
- Knowledge
- Agents
- Automations
- Evidence
- ELO Evolution

## Workspace rule

The workspace presents and invokes existing ELO capabilities. It must not redefine Cognitive Core contracts, governance rules, canonical memory or source-of-truth systems.

## Decision view

Every consequential recommendation shown to a user should expose, when available:

- context;
- evidence;
- provenance;
- assumptions;
- risks;
- alternatives;
- recommendation;
- authorization state;
- resulting outcome.

## Tenant isolation

UI/API requests must preserve tenant and principal boundaries end-to-end.
