# ELO Knowledge Engineering — Local Agent Rules

## Scope

This directory governs how knowledge is acquired, normalized, structured, retrieved, evaluated, and traced.

## Distinctions

Preserve the distinction between:

- source knowledge;
- organizational experience;
- consultant input;
- hypothesis;
- evidence;
- recommendation;
- decision.

## Knowledge quality

For important knowledge record, when available:

- source;
- provenance;
- date;
- scope;
- applicability;
- limitations;
- validation status.

## Experience learning

A historical solution is not automatically reusable. Evaluate contextual similarity, constraints, outcomes, and non-applicability conditions.

## External sources

Do not treat web/AI-generated information as authoritative merely because it is plausible. Preserve source identity and verification status.

## Cognitive Consulting

Support relevance-driven retrieval rather than indiscriminate search. The problem context should determine which knowledge domains and sources are queried.
