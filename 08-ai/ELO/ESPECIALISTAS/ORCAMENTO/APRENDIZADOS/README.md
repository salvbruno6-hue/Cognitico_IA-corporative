# Aprendizados de Orçamento — ELO

Este é o **destino canônico único** para aprendizados originados de Solicitações de Orçamento analisadas pelo ELO.

## Regra de roteamento

Todo aprendizado específico de uma SO, quando derivado do ciclo de Análise de Solicitações → PTS Técnica → Orçamento → PTS Pós-Orçamento, deve ser registrado aqui.

Exemplos:

- `SO_104_26_...md`
- `SO_120_26_...md`
- `SO_150_26_...md`
- `SO_156_26_...md`
- futuras SOs

## O que permanece fora desta pasta

- **Supabase:** memória consultiva estruturada, especialmente cálculos e evidências quantitativas.
- **04-knowledge-handbook:** conhecimento corporativo já consolidado/canônico, quando houver promoção formal a conceito, instrução ou diretriz geral.
- **00-core:** regras normativas do Core.
- **memory/evolution:** trilha técnica de eventos/evolução; não é destino do aprendizado consolidado de orçamento.

## Proveniência obrigatória

Cada aprendizado deve preservar a SO e o documento/experiência de origem. Referências de outras SOs são consultivas e não podem ser confundidas com a origem da SO corrente.

## Governança

ELO permanece como orquestrador cognitivo. A existência de um arquivo nesta pasta não significa promoção automática a `RULE`. O aprendizado deve conservar sua classificação e status de validação.
