# APRENDIZADOS — DESTINO CANÔNICO

Esta pasta é o destino oficial dos conhecimentos gerados pelo ELO APRENDER no domínio de orçamento.

## Deve registrar

- histórico de cada SO processada;
- memória de decisão;
- memória de cálculo;
- precedentes reutilizáveis;
- regras e padrões candidatos;
- regras validadas;
- lógica de composição e dimensionamento;
- lógica de identificação de produto/modelo;
- excedentes e adaptações aprendidos;
- premissas, evidências e limitações.

## Regra

Cada SO deve manter sua origem identificável. O ELO deve separar fato histórico, cálculo, inferência, precedente e regra validada.

## Persistência

O conhecimento canônico é versionado no Git e sua representação estruturada de consulta deve ser persistida no Supabase. Os dois registros devem manter vínculo por SO, item, tipo de conhecimento e origem.
